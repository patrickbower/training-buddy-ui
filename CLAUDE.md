This is a mobile-first chat interface for an AI-powered running coach called Training Buddy.

This project uses pnpm.

Build: `pnpm build`
Type check: `pnpm typecheck`
Lint: `pnpm lint`
Test (unit): `pnpm test`
Test (e2e): `pnpm test:e2e`
